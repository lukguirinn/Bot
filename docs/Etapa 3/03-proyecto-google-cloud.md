# 3.03 — Proyecto Google Cloud

## Objetivo
Crear el entorno de Google Cloud donde funcionará la integración de Calendi.

## Actividades
- Crear o seleccionar un proyecto de Google Cloud.
- Identificarlo con el nombre Calendi.
- Configurar los datos generales del proyecto.
- Revisar los permisos de administración.
- Verificar que el proyecto esté activo.

## Consideraciones
Las credenciales privadas no deben guardarse en GitHub.

## Resultado esperado
Contar con un proyecto de Google Cloud preparado para configurar los servicios de Google Calendar.
