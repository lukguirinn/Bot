# 3.05 — Pantalla de consentimiento OAuth

## Objetivo
Configurar la pantalla que verá cada usuario cuando conecte su cuenta de Google.

## Actividades
- Configurar el nombre de la aplicación: Calendi.
- Definir el correo de soporte.
- Configurar los datos de contacto del desarrollador.
- Seleccionar el tipo de audiencia correspondiente.
- Configurar los permisos solicitados.
- Revisar los dominios autorizados cuando corresponda.

## Criterios
La pantalla debe identificar claramente a Calendi y explicar qué permisos necesita para acceder al calendario.

## Resultado esperado
Pantalla de consentimiento configurada para iniciar las pruebas de autenticación.
