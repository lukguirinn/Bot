
# Alcance del proyecto

## 1. Descripción

Calendi es un bot de WhatsApp diseñado para facilitar la gestión de calendarios y recordatorios mediante mensajes escritos en lenguaje natural.

El usuario podrá interactuar con el bot sin necesidad de instalar una aplicación adicional.

## 2. Objetivo general

Desarrollar un asistente virtual que permita administrar eventos y recordatorios de manera sencilla, utilizando WhatsApp como interfaz principal.

## 3. Público objetivo

Personas que necesiten organizar sus actividades personales, laborales o académicas mediante un calendario.

## 4. Funcionalidades del MVP

La primera versión del proyecto incluirá:

### Gestión de eventos

- Crear eventos.
- Consultar eventos.
- Modificar eventos.
- Eliminar eventos.

### Gestión de recordatorios

- Configurar fecha y hora.
- Recibir notificaciones automáticas.
- Consultar recordatorios pendientes.

### Integración con calendario

- Conectar una cuenta de Google Calendar.
- Crear eventos en Google Calendar.
- Consultar eventos existentes.
- Actualizar eventos.

### Interacción mediante WhatsApp

- Recibir mensajes del usuario.
- Procesar solicitudes.
- Responder con información clara.
- Solicitar datos faltantes.

## 5. Funcionalidades futuras

Se consideran para futuras versiones:

- Administrar múltiples calendarios.
- Crear eventos recurrentes.
- Gestionar tareas.
- Compartir eventos.
- Incorporar otros proveedores de calendario.
- Ofrecer planes comerciales.

## 6. Fuera del alcance inicial

La primera versión no incluirá:

- Aplicación móvil propia.
- Plataforma web para usuarios.
- Integraciones con múltiples servicios externos.
- Inteligencia artificial avanzada para cualquier tipo de conversación.

## 7. Requisitos funcionales

- RF01: El sistema debe recibir mensajes de WhatsApp.
- RF02: El sistema debe permitir crear eventos.
- RF03: El sistema debe permitir consultar eventos.
- RF04: El sistema debe permitir modificar eventos.
- RF05: El sistema debe permitir eliminar eventos.
- RF06: El sistema debe permitir configurar recordatorios.
- RF07: El sistema debe integrarse con Google Calendar.
- RF08: El sistema debe responder a las solicitudes del usuario.

## 8. Requisitos no funcionales

- RNF01: El sistema debe ser fácil de utilizar.
- RNF02: El sistema debe proteger los datos del usuario.
- RNF03: El sistema debe responder en tiempos razonables.
- RNF04: El sistema debe ser mantenible y escalable.
- RNF05: El sistema debe contar con mecanismos de control de errores.

## 9. Criterio de finalización del MVP

El MVP se considerará funcional cuando un usuario pueda:

1. Enviar un mensaje al bot.
2. Crear un evento.
3. Consultar sus eventos.
4. Modificar o eliminar un evento.
5. Recibir un recordatorio.
6. Visualizar los eventos en Google Calendar.
