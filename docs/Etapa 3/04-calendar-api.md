# 3.04 — Habilitación de Google Calendar API

## Objetivo
Habilitar la API que permitirá a Calendi comunicarse con Google Calendar.

## Actividades
- Ingresar al proyecto de Google Cloud.
- Acceder a la biblioteca de APIs.
- Buscar Google Calendar API.
- Habilitar el servicio.
- Verificar que figure como habilitado.

## Uso previsto
La API permitirá que Calendi acceda a los calendarios autorizados por cada usuario.

## Seguridad
El acceso dependerá de los permisos OAuth concedidos por cada usuario.

## Resultado esperado
Google Calendar API habilitada y disponible para el proyecto.
